## [1.1.0] - 2026-04-28

### Phase 3 — Polish & Completeness

#### Completeness
- Expanded `FileCategory` coverage with 21 new file extensions:
  - **Images**: `.heic`, `.heif`, `.ico`
  - **Documents**: `.numbers`, `.pages`, `.keynote`, `.csv`, `.md`
  - **Scripts**: `.swift`, `.ts`, `.tsx`, `.jsx`, `.go`, `.rs`, `.kt`, `.rb`, `.cs`
  - **Audio**: `.aiff`, `.opus`
  - **Archives**: `.xz`, `.iso`

#### UX Polish
- Added confirmation alert before "Clean Empty Folders" (irreversible operation).
- Added confirmation alert before "Apply Suggested Categories" showing the number of moves.
- "Select Directory" button now disabled while an operation is in progress.
- Analysis button in Storage Insights now disabled while analysis is running.
- `isApplying` progress spinner added to Notes Assistant.
- Empty state (`ContentUnavailableView`) shown in Notes Assistant before first fetch.
- Empty state shown in main detail area when no sidebar section is selected.

#### Accessibility
- `accessibilityLabel` and `accessibilityHint` added to all major controls in File Organizer, Storage Insights, and Notes Assistant views.
- Evaluation progress view exposes `accessibilityValue` with note count.
- Insights list rows combined as single accessibility elements.

#### Code Cleanup
- Removed `NotesService.deleteNote` (confirmed unused).
- Removed stale `System_Org.code-workspace` artifact.
- Removed all unnecessary `public` access modifiers from executable target sources (72 instances across 13 files).
- Fixed leading-space bug in Notes Assistant refresh-failure status message.
- Added `NSAppleEventsUsageDescription` to the bundled `Info.plist` generated by the packaging script (required for Notes automation on macOS 14).
- Added documentation comment in `SwiftOrganizerXApp.swift` for app icon asset placement.

#### Tests
- Added 25 new `FileCategoryTests` covering all new extensions and case-insensitivity.

## [1.0.0] - 2026-04-07

### Phase 2 — MVVM Architecture & AI Integration

- Introduced three `@MainActor ObservableObject` ViewModels: `FileOrganizerViewModel`, `InsightsViewModel`, `NotesAssistantViewModel`.
- All file I/O and AppleScript calls run via `Task.detached`; UI state updates run on `MainActor`.
- AI note evaluation uses bounded `TaskGroup` with concurrency limit of 3.
- API key migrated from `UserDefaults` to Keychain via `KeychainService` (one-time migration on first launch).
- Consent gate: user must approve sending note data to OpenAI before first evaluation.
- `InsightsView` shows error messages in UI rather than console only.
- `FileOrganizerView` and `InsightsView` show `ProgressView` / disable buttons during active work.
- Added `ContentUnavailableView` empty states in `InsightsView`.

### Phase 1 — Core Features

- Added OpenAI-backed Apple Notes evaluation and suggested folder application.
- Added release packaging via `scripts/package_macos_app.sh`.
- Added recursive storage insights and Pareto-style analysis.
- Undo support for the most recent file organization batch.
- Deep removal of empty subfolder trees.
- Native SwiftUI interface with Dark Mode support.
